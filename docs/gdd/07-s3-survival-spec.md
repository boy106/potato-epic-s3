## 0. 已拍板决策（任务书定稿，本文档不可推翻）

1. **离线单机 + 本地存储**，无服务端，所有数值本地可算；药物/投掷物库存复用搜打撤仓库 `potato:sfe:stash`（sfe_rules.js:56）。
2. **肢体血量给 A/B 两方案并推荐一个**（本文 §5，推荐方案 B），推荐标准 = 实现成本 / 手感 / 与现有倍率制的兼容性。
3. **趴姿、飞扑是全新姿态状态**，接在现有 `PLAYER_H` 姿态状态机（stand/crouch/swim）上扩展。
4. **手持投掷物为全新物品线**（手雷/闪光/烟雾 3 种），榴弹发射器的 `grenade:!0` 爆炸路径（bundle.js launcher 定义）为物理复用来源。
5. **药物读条与撤离读条的边界、投掷物对 AI 的作用**必须有定死规则（本文 §8）。
6. 每系统给可测验收标准，全文总验收 16 条（§9）；结尾开放问题 3~5 条（§10）。

**★ 倾向性结论标注**：任务书明确要求"给结论"的开放点标注 ★，由设计侧拍板，实现与测试按此执行；用户不同意时只改对应条目，不动其他章节。

## 1. 概述与系统总览

### 1.1 六系统定位

| # | 系统 | 一句话 | 服务的设计目标 |
| --- | --- | --- | --- |
| ① | 体力条 | 冲刺/跳跃/飞扑消耗、按姿态差异化恢复的移动资源 | 搜打撤 720² 大图（06-§6）上的跑图节奏与"贪心决策"张力：体力限制了无脑拉扯 |
| ② | 趴姿 | 第三姿态：低 hitbox + 精度加成 + 重移动惩罚 | 遭遇战的"架枪"深度；接飞扑落地态 |
| ③ | 飞扑 | 冲刺中触发的扑倒位移，落地强制接趴 | 进攻性进点/避险的高光操作，代价是 0.85s 禁射 |
| ④ | 肢体血量 | 部位损伤 debuff（方案 B，推荐）| 不推翻现有倍率制（02-§3.1）的前提下给"打腿/打手"以长期意义 |
| ⑤ | 针剂与药物 | 5 种读条消耗品 | 搜刮价值锚（T0/T1 容器不再是纯垃圾）+ 战斗段资源管理 |
| ⑥ | 投掷物 | 3 种手持投掷（破片/闪光/烟雾） | 遭遇战工具化：AI 行为可被道具操纵，撤离段反狙击 |

### 1.2 生效范围：**★ 仅搜打撤模式启用，其余模式零开销旁路**

| 模式 | 体力 | 趴/扑 | 肢体 debuff | 药物 | 投掷物 |
| --- | --- | --- | --- | --- | --- |
| 搜打撤 PVE | ✅ | ✅ | ✅ | ✅ | ✅ |
| 沙盒世界 | ❌（沿用饥饿 food 体系） | ✅（姿态属底层能力，不隔离） | ❌ | ✅（合成获取） | ✅（合成获取） |
| 天梯/乱斗/靶场/约战 | ❌ | ❌ | ❌ | ❌ | ❌ |

理由：

1. **竞技公平**（对齐 05-§6 惯例"凡影响对局操作的开关，状态变更只能发生在对局外"）：天梯统一装备 + 固定枪池的公平感（00-§2 P2）是项目支柱，往竞技模式注入体力/姿态 debuff 会改变 TTK 与手感基线，收益不成比例。
2. **最小改动面**：姿态与投掷物属底层能力（沙盒可玩），但体力/debuff/药物只在 `worldMeta.sfe` 分支驱动（对齐 sfe_rules.js:125 `matchOn()` 的模式判定方式），竞技路径保持现状零开销。
3. 沙盒启用姿态与合成线（但不启用体力），给搜打撤的投掷物/药物提供"沙盒试玩→带装出击"的上游（对齐 06-§5.3 沙盒与搜打撤共享物品 id 体系）。

## 2. 系统一：体力条（Stamina）

### 2.1 资源定义

| 参数 | 值 | 置信度 |
| --- | --- | --- |
| 上限 | **100**（整数，HUD 显示为条 + 百分比） | 设计·中 |
| 出局初始值 | 进图落地 = 100；死亡重开 = 重置 | 设计·高 |
| 恢复延迟 | 停止消耗后 **0.8s** 才开始恢复（防抖：跳跃连打不清空回复窗口） | 设计·中 |
| 跨局持久 | 否，对局制局内资源（对齐 06"局内即抛"） | 设计·高 |
| 与饥饿关系 | SFE 局内 food 锁 20（F3），体力为唯一移动资源；沙盒不启用体力、维持 food>6 门槛 | 设计·高 |

### 2.2 消耗表

| 行为 | 消耗 | 备注 |
| --- | --- | --- |
| 冲刺（移动） | **8 / 秒** | 100 满体力最长连续冲刺 **12.5s**；与现有 sprint ×1.3 移速叠加（F2），不改变移速数值 |
| 跳跃 | **12 / 次** | 落地后才开始计恢复延迟；水中游泳不消耗（SFE 地图水域有限，从简） |
| 飞扑 | **25 / 次** | 触发条件见 §4.1；体力 <25 时飞扑键无效 |
| 近战挥击 | **6 / 次** | 近战需体力 ≥10 才能挥击；体力不足时挥击键无效（不硬扣） |
| 开镜持枪 | 0 额外消耗 | 开火消耗仅走弹药，不在体力上加税（射击手感不动） |
| 蹲/趴移动 | 0 额外消耗 | 慢速移动本身享受恢复（见 2.3，趴姿恢复最高，鼓励"趴着喘"） |
| 受击 | 0 | 受击惩罚已经存在于伤害与撤离打断（F6），不叠体力税 |

### 2.3 恢复表（按姿态差异化）

| 姿态/状态 | 恢复 / 秒 | 设计意图 |
| --- | --- | --- |
| 站立静止 | **15** | 基准 |
| 蹲（静止/蹲行） | **12** | 蹲不是休息姿态 |
| 趴（静止/蠕动） | **18** | 趴 = 最快回复 + 精度加成，但牺牲机动与视野——三者自洽 |
| 行走（非冲刺） | **10** | 走路即可回血，大图跑图不必站桩 |
| 开镜中 | **8**（各姿态基础上再 ×0.53→统一减为 8） | 架枪时回复放缓但不冻结 |
| 冲刺/飞扑空中 | 0（不恢复） | — |

> 实现注记：开镜恢复取"当前姿态速率与 8 的较小值"，单条 `min(poseRate, 8)` 即可，不建双表。

### 2.4 阈值行为

| 阈值 | 行为 |
| --- | --- |
| 体力 < **15** | 不可进入冲刺；已冲刺者继续冲刺直到 0 或松开（不提前掐断，避免"15 处粘滞"手感） |
| 体力 = **0** | 冲刺立即结束，进入 **1.5s 喘息**：移速 ×0.8、不可冲刺/跳跃/飞扑，喘息结束体力回到 ≥10 才解禁（喘息期内按恢复速率自然回升，10/0.8s 延迟后到达） |
| 体力 < **25** | 不可飞扑（§4.1） |
| 体力 < **10** | 不可近战挥击 |
| UI 反馈 | 条低于 15% 变红 + 喘息时准星旁呼吸图标；不做全屏遮挡（性能与视野克制，对齐 06-§7.2 HUD 风格） |

### 2.5 UI 与输入

- HUD：体力条贴现有血条下方（移动端左下、桌面端同位），宽 = 血条同宽，纯色填充无渐变（低端机省绘制）。
- 桌面键位：沿用现有冲刺键（ControlLeft，F8），无新键；体力是被动资源。
- 移动端：沿用现有疾跑按钮（touch.js sprint toggle），无新键。

## 3. 系统二：趴姿（Prone）

### 3.1 姿态定义

| 参数 | 值 | 置信度 |
| --- | --- | --- |
| 姿态枚举 | `pose` 新增 `prone`（F1 状态机扩展），`PLAYER_H.prone = 0.6`（复用 swim 高度值，不新增碰撞调参项） | 设计·中 |
| eye 高度 | 0.85 × h 现行公式不变 → 趴姿 eye ≈ **0.51** 方块（取 0.5） | 引用·高 |
| hitbox | 高 0.6、宽不变（现 w） | 引用·高 |
| 进入条件 | 站立/蹲姿按趴键 → 趴（趴下永远允许，仅需 0.6 高空间）；水中禁趴（inWater 时按键无效，swim 姿态优先级更高，F1 链序不变） | 设计·中 |
| 起立条件 | 需头部空间：`fits(stand)` → 站；不满足则试 `fits(crouch)` → 蹲；都不满足保持趴 | 引用·高（复用 F1 fits 链） |
| 姿态过渡 | 0.3s 动画期：不能开火、不能开镜、不能再次切换姿态 | 设计·中 |
| 趴↔蹲↔站链序 | 趴键：站/蹲 → 趴；跳跃键或再按趴键：趴 → 蹲 → 站（跳跃键在趴姿 = 尝试起立，不跳） | 设计·中 |

### 3.2 趴姿战斗与移动数值

| 项 | 值 | 备注 |
| --- | --- | --- |
| 散布系数 | **×0.6**（对腰射与开镜均生效，作用在 `spreadNow()` 结果上，与握把 ×0.75 乘法叠加） | 02-§3.2 公式的第三层系数；趴姿满配步枪开镜 ≈ 现状开镜散布 ×0.45 |
| 移速 | 基础 ×**0.25**（比 sneak ×0.3 更慢） | 挂 F2 乘法链 |
| 冲刺 | 禁止（sprinting 强制 false，F2 判定链已有 `!this.sneaking && !this.crawling` 原样扩写 `!prone`） | 引用·高 |
| 跳跃 | 禁止（跳跃键语义改为起立，见 3.1） | 设计·中 |
| sneakEdge 保护 | 趴姿沿用潜行边缘保护（不掉边） | 设计·中（趴姿贴边蠕动是主要用法，掉边体验灾难） |
| 视角 | yaw 全量；pitch 钳制 [−80°, +20°]（趴着不该能大幅抬头，钳制值联调可调） | 设计·低 |

### 3.3 与命中判定的交互（已知副作用，明示不修）

现有四肢判定"命中点低于眼睛 −0.3 且在腿部盒内"（02-§3.1）：趴姿 eye≈0.5 时，命中全身高度几乎都低于 0.2 → **趴姿玩家被命中时四肢倍率 ×0.75 占比大幅上升**，等效减伤。这是趴姿防御收益的一部分，**首版接受不做特判**（记入开放问题 Q5，联调期若趴姿过肉再调四肢判定阈值）。

## 4. 系统三：飞扑（Dive）

### 4.1 触发条件（全部满足才触发）

| 条件 | 值 |
| --- | --- |
| 状态 | `sprinting == true` 且 `onGround`（F2） |
| 输入 | 冲刺中按下趴键（桌面 = 趴键位新增；移动端 = 趴/扑共用键，见 §3/§8.6） |
| 体力 | ≥ 25（触发即扣 25） |
| 空间 | 前方 1 方块高度可通行（撞墙判定提前结束，见 4.4） |

### 4.2 扑行数值（定死）

| 参数 | 值 | 置信度 |
| --- | --- | --- |
| 峰值扑速 | **7.0 方块/s**（≈ 现冲刺 5.6 的 1.25 倍） | 设计·中 |
| 扑程 | **≈3.5 方块**（7.0 起速 × 0.99 阻力衰减 × 0.55s，实测容差 ±0.5） | 设计·中 |
| 扑时长 | **0.55s** 后自动落地 | 设计·中 |
| 垂直轨迹 | 起跳瞬间 +0.25 方块小抛物线（跳上 1 格台阶），重力同 Grenade 量级（F5） | 设计·中 |
| 方向锁定 | 扑出瞬间锁定水平方向向量，扑中**不跟随转向**；视角可用（lookWrite 正常），落地前可预先瞄准 | 设计·中 |
| 扑中禁操作 | 开火、开镜、换弹、药物、投掷全部禁用 | 设计·中 |
| 落地禁射 | 落地（接趴）后 **+0.3s** 才能开火 → 单次飞扑总禁射 **0.85s** | 设计·中 |
| 体力 | 扣 25；扑中体力不额外消耗 | 设计·高 |

### 4.3 落地状态：**★ 强制接趴，不自动起立**

- 落地瞬间 hitbox 立即转 `prone`（0.6 高，与 §3.1 进入条件一致，低矮空间天然兼容）。
- 玩家自行决定起立（跳跃键/趴键起立链）——"扑进掩体 → 趴着架枪 → 站起"是设计好的三拍，自动起立会废掉第三拍。
- 落地接趴享受趴姿全部规则（散布 ×0.6、恢复 18/s、移速 ×0.25）。

### 4.4 中断与异常

| 场景 | 行为 |
| --- | --- |
| 扑中撞墙（水平速度骤降 >60%） | 立即结束扑行，扣 5 体力（碰撞代价），落地接趴；不扣血（首版不做撞击伤害） |
| 扑出悬崖 | 扑行照常 0.55s 计时结束，之后正常重力坠落，落地接趴；坠落伤害走现有 fall 路径 |
| 扑中受击 | 正常受伤，扑行不中断（受击惩罚已够，双重惩罚手感崩） |
| 扑入水中 | 落水即转 swim 姿态，扑行结束，体力不退 |
| 扑键连打 | 扑行中趴键输入忽略；落地后 0.5s 内不可再扑（防扑链） |

## 5. 系统四：肢体血量（两方案，★推荐方案 B）

### 5.1 现状基线

单一 HP 池（玩家 20，F4）+ 部位倍率：爆头 ×2（左轮 ×3）、四肢 ×0.75、躯干 ×1（02-§3.1，N-40）。**无肢体独立血池**。命中回调已区分 head/limb/body（F4），这是两方案共同的免费地基。

### 5.2 方案 A：Tarkov 式六分区独立血池

```
六分区：头 8 / 胸 20 / 左臂 12 / 右臂 12 / 左腿 14 / 右腿 14（合计 80 部位血 + 主 HP 20）
伤害先扣命中部位血量；四肢部位血 ≤0 → 黑肢：
  黑肢 debuff：手臂黑 = 单手武器散布 ×1.5；腿黑 = 移速 ×0.6、禁冲刺
  溢出规则：命中已黑四肢的伤害 ×40% 溢出到胸腔；胸腔血 ≤0 或头部血 ≤0 → 死亡
  主 HP 池取消（部位血即总血）或保留（双层制）——Tarkov 为前者
```

| 评估维度 | 评价 |
| --- | --- |
| 实现成本 | **高**：命中点 → 六分区映射需要把 limb 粗判（F4 的 head/limb/body 三分）细化为左右臂/腿（需要命中点相对身体左右半边的判别）；UI 需要六格部位面板；死亡判定从 HP≤0 改为复合条件；药物需逐部位回血逻辑 |
| 手感 | **重**：黑肢+溢出是硬核生存心智；单机 PVE 无队友救援，一条腿黑了没有"队友扎针"解法，只有自己蹲角落读条 3~6s——在 8~10min 中位局长（06-§3.1）里一次失误的惩罚半径过大，死亡挫败感与 06-§1.2"死亡有重量但结算克制"的基调节奏冲突 |
| 与倍率制兼容性 | **差**：四肢 ×0.75 倍率与部位血池语义冲突（倍率意味着"打四肢更不疼"，血池意味着"打四肢残废但胸口不扣"），两者并存需要精心重算全枪表 TTK；爆头 ×2 与"头 8 血"叠加后 TTK 重算面覆盖全部 11 枪 |

### 5.3 方案 B：轻量混合（★推荐）

**维持现有倍率制与单一 HP 池完全不动**，在其上叠加**部位损伤值**（debuff 计量，非血量）：

```
部位损伤值：左腿 / 右腿 / 左臂 / 右臂 四轨，各 0~100，初始 0
累计方式：命中四肢时，本次伤害（已乘 ×0.75 倍率后的值）× 3 计入对应部位损伤轨
  （HP 20 制下单发步枪伤 4.5×0.75≈3.4 → 损伤 +10；两梭子步枪打腿 ≈ 满损伤）
阈值 debuff（每一轨独立判定，取该轨累计值）：
  腿损 ≥40：移速 ×0.85
  腿损 ≥70：移速 ×0.7 且禁冲刺、禁飞扑
  臂损 ≥40：开镜晃动振幅 +50%（sway 层，经 lookWrite 同链施加，F7）
  臂损 ≥70：换弹时间 ×1.3、腰射散布 +0.5
损伤恢复：自然恢复 = 0（首版不做自然恢复，制造药物刚需）；药物恢复见 §6
死亡判定：仍为 HP≤0，完全不改；损伤永不直接致死
```

| 评估维度 | 评价 |
| --- | --- |
| 实现成本 | **低**：不需要命中分区细化（limb 二值已够；左右判定可用命中点 x 相对身体中轴的符号，一行代码，做不准就先合并"双臂/双腿"两轨，UI 同步简化）；无 TTK 重算；debuff 挂 F2 速度链与 F7 视角链，均为现有乘法结构 |
| 手感 | **中**：惩罚可感知但不致命，打腿减速/打手晃枪给"打部位"以战术意义，同时保留"残血撤退"的传统 FPS 直觉；移动端无部位面板操作负担 |
| 与倍率制兼容性 | **完美**：倍率照算（伤害进 HP），损伤值是平行的第二条账，互不干扰；未来升级方案 A 时损伤轨与 debuff 逻辑可整体迁移 |

**★ 结论：首版采用方案 B。** 三标准（成本/手感/兼容性）全面占优；方案 A 列为 PVP 搜打撤（06-§8.4 P2/P4）立项时的重审项——届时"黑肢+队友救援"的博弈才有支撑结构。方案 B 的损伤轨设计已按"可平移进方案 A"预留。

## 9. 验收标准（共 16 条，可直接转用例）

**体力条**

1. 搜打撤对局内 HUD 显示体力条；满体力连续冲刺至耗尽实测 12.5s ±0.5s（8/s 消耗）；停止消耗 0.8s 后开始恢复。
2. 姿态差异化恢复生效：站立 15 / 蹲 12 / 趴 18 / 行走 10（±10% 容差）；开镜时恢复为 min(姿态速率, 8)。
3. 体力 <15 无法进入冲刺；冲刺中耗尽立即停止并触发 1.5s 喘息（移速 ×0.8、禁冲刺/跳跃/飞扑）；体力 <25 飞扑键无效、<10 近战挥击键无效。
4. 天梯/乱斗/靶场对局中无体力条、冲刺不受体力影响（手感与现状一致，模式隔离生效）。

**趴姿与飞扑**

5. 趴姿 hitbox 高 0.6、eye≈0.5：1 格高洞可趴入；在头部空间不足处起立自动回退为蹲而非卡死。
6. 趴姿散布系数 ×0.6（与握把 ×0.75 乘法叠加，实测满配步枪趴姿开镜散布 ≈ 站立开镜 ×0.45 ±10%）；趴姿移速 ×0.25、禁冲刺禁跳跃；姿态切换 0.3s 内不能开火。
7. 冲刺中按趴键触发飞扑：峰值 7 方块/s、扑程 3.5±0.5 方块、0.55s 后自动接趴姿；扑中 + 落地 0.85s 内不能开火/开镜；落地不自动起立。
8. 飞扑撞墙立即结束并接趴（扣 5 体力）；体力不足 25、非冲刺状态、扑后 0.5s 内均无法触发飞扑。

**肢体血量（方案 B）**

9. 腿部损伤累计生效：≥40 移速 ×0.85、≥70 移速 ×0.7 且禁冲刺禁飞扑；臂损 ≥40 开镜晃动 +50%、≥70 换弹 ×1.3 且腰射散布 +0.5；阈值解除有 −10 迟滞。
10. 损伤只经药物恢复（自然恢复为 0）；死亡/结算后损伤与 debuff 全部清零；HP 死亡判定不受损伤影响（损伤永不直接致死）。

**药物**

11. 绷带读条 3s 四肢损伤每轨 −30；急救包 6s HP+10 且清空全部损伤；读条中开火/受击/切换物品打断且不消耗物品；读条允许 ×0.5 缓移（含趴姿）。
12. 肾上腺素/止痛针/能量饮料效果、时长、结束后疲劳与 §6.2 表一致；同名增益不叠加仅刷新；HP 满时急救包不可用。

**投掷物**

13. 三种投掷物引信（3.5/1.8/2.0s）、满蓄初速 18 方块/s、手雷爆炸半径 3（与榴弹发射器同路径）、中心 60 衰减至 8、自伤 ×0.5 均与 §7.2 一致。
14. 闪光弹：面向锥角内白屏 2.5s + 2.5s 渐退、背对/遮挡 0.8s；L1/L2 AI 索敌中断 4s、L3 2s；「闪光强度」滑条生效（50%~100%）。
15. 烟雾弹遮挡半径 2.5/高 3 挡 AI 视线（raycast 判定）、不挡子弹；同屏 2 团烟雾粒子峰值 ≤120（低端 ≤60），烟雾期间最低端设备帧时长增量 <1.5ms。

**联动与工程约束**

16. 撤离读条中允许药物双读条并行（互不保护、各按各的打断规则）；撤离读条中投掷/开火打断读条且进度不清；DEPLOY 段投掷禁用药物可用；全部新增数值集中于单一 `SURV.TUNE` 调参块，无散落硬编码（代码走查确认）。
