# 03 · 经济与解锁（现状版 GDD）

> 出处：`mods/xzguns/bundle.js` skins/经济模块（coins 引擎全函数逐字可读）、`js/pack4.js`（potato.js 衣柜/枪皮 UI、account.js 账号门、shareholders.js、companion.js、cosmetics.js）。数值见 `numbers.md` N-62~N-90。

## 1. 概述

单一货币「土豆币」，来源全部免费（游玩时长、首胜、签到、活动），消耗集中在枪皮升级与刀涂装；解锁门分四类：段位（晋升皮肤）、关注/三连（薯核 CORE + 刀）、活动签到（丰收节皮肤 + 装饰）、股东（动态披风）。**无任何付费入口**（欢迎页明文「永久免费」）。

## 2. 玩家价值

- 所有付费墙替代为「时间/互动」墙，与 B站 UP 主涨粉闭环。
- 皮肤 4 级成长给长线目标：无特效 → 专属击杀反馈 → 专属检视动作 → 终结特效（全场可见，N-71）。

## 5. 边界与异常

- 币不够买涂装/升级：报错文案「土豆币不够：…」。
- 未解锁就尝试装备：报错「还没有解锁这款皮肤/这把刀」。
- 重复买涂装：报错「已经有这种涂装了」。
- `keep()` 同步：gate 变化后仍保留已获得的 harvest 系与已买涂装（关注被取消时 core 系会被回收——`triple` gate 下 core 不保留，中置信）。
- 装扮奖励「永久保留」（活动结束文案明示）。
- 币余额、今日已得、升级等级随账号（登录/云存档）迁移；游客身份走 pm 服务器。

## 6. 耦合

- 01 排位：段位 → 晋升皮肤；首胜判定。
- 04 留存：签到（连续/活动）、股东、关注门全部产币或产外观。
- 02 战斗：材料商店驱动沙盒采集；皮肤特效挂在枪械击杀/检视事件上。
