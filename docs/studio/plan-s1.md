# 土豆史诗 · S1 作战计划（打磨 + 基线回填）

> 主理人：游承峰 · 2026-11-21
> 阶段：Phase 6 打磨（主轴） + 基线回填（支线）
> 评审强度：**lean** —— 全轮仅设 2 道质量门
> 硬约束：**仅有 build 产物，无原始源码仓库**

---

## 1. 本轮目标

1. 把不可维护的压缩 build 还原为**结构级可维护的源码树**，让后续修复可 diff、可回滚、可重建。
2. 建起**最小可用的回归网**（黑盒烟雾测试 + 缺陷分级），让改动不再靠"凭感觉验证"。
3. 逆向出**现状即规格**的设计与架构基线，让"改这个会破坏什么"有据可查。
4. 立起**发布工程**基本盘，让版本、热修、回滚有章可循。

**非目标**：不做新玩法、不做第 2 赛季、不改排位数值、不做服务端改动、不迁移引擎。

### W0 · 源码树还原（P0，地基）

- 解析 4 个 pack 的 `[["js/模块名","代码"],...]` 结构，按原顺序拆出 102 个模块到 `src/js/`
- `index.html` 改为按原顺序的外部 `<script src>` 加载，去除内联 loader

- 生成模块依赖图 `docs/architecture/module-map.md`

- **完成判据**：本地起服务后能启动、进大厅、单机可玩；与线上 build 行为一致
