# 土豆史诗 - S3 玩法扩展（离线版）

这是「土豆史诗」S3 赛季玩法扩展的离线版本，包含现代枪械模组等内容。

## 在线试玩

访问地址：

**https://boy106.github.io/potato-epic-s3/**

## 本地运行

直接用浏览器打开 `index.html` 即可（推荐使用 Chrome / Edge）。

或者使用本地服务器：

```bash
# Python
python -m http.server 8080

# 或者 Node.js
npx serve .
```

然后访问 http://localhost:8080

## 包含内容

- 核心游戏资源
- **小哲的现代枪械** 模组（xzguns）
  - 10 把现代枪械（手枪、左轮、冲锋枪、霰弹枪、步枪、突击步枪、轻机枪、狙击、双管、榴弹）
  - 3D 模型 + 动画
  - 子弹穿透、配件改装
  - 黑市平板商店
  - 专用靶场地图
