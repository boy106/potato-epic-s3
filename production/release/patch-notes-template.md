# POTATO EPIC 玩家补丁说明模板

用途：B站 Toy 更新公告、游戏内 news、社区置顶。玩家版只写玩家能感知的变化；内部堆栈、文件路径和完整哈希放变更记录，不堆进公告。

<一句有温度但不夸张的开场：本次解决什么问题，或带来什么体验。>

## B. 写作与发布规则

1. **先写结果，再写原因**：玩家先看到“可以正常进入房间”，而不是内部模块名。
2. **可复现**：修复项包含触发场景；平衡项尽量给出调整前后数值。
3. **不冒充已验证**：未经验证的内容不得写“已修复”；示例不得直接当真实公告发布。
4. **已知问题不隐藏**：Blocker 未清不得用公告代替修复；豁免须有用户明确批准。
5. **数据优先**：云存档、签到、奖励、股东名单或天梯受影响时必须单独说明。
6. **版本一致**：标题、正文、游戏启动页、`GAME_BUILD` 与实际上传包一致。
7. **回退要坦诚**：说明回退版本、影响、数据兼容和下一次更新入口，不将回退包装成新功能。

## C. 示例：`S1 · 2026.11.14a`

> **仅为格式示例，基于当前包可见能力编写，不代表这些能力都在该版本新增，也不是已审批的真实公告。**

# 土豆史诗｜2026.11.14a 更新公告

第一赛季的战斗装备与训练入口已经集结，欢迎回到土豆战场。
- 赛季：S1
- 版本：2026.11.14a
- 平台：B站 Toy
- 更新方式：重新进入游戏后生效

## 新内容
- **现代枪械体验**：可体验手枪、左轮、冲锋枪、霰弹枪、步枪、突击步枪、轻机枪、狙击枪、双管枪与榴弹等十类武器。
- **改装与靶场**：通过黑市平板查看武器、弹药和配件；从模组卡片进入靶场练习射击与换弹。
- **天梯对战**：支持 1V1 天梯，对局采用五局三胜展示规则。

## 修复
- 示例写法：修复了 <具体版本与场景> 中换弹后无法开火的问题，现在完成换弹即可恢复射击。
- 无实测变更记录时，本分区写“本次未包含已确认的修复项”，不要虚构条目。

## 平衡调整
- 当前规则示例：爆头伤害为 ×2，四肢伤害为 ×0.75；移动射击会扩大散布，停稳后更精准。
- 若这些数值并非本版变化，标题应改为“当前战斗规则”，避免误导玩家。

## 已知问题
- 当前候选包的皮肤预设资源仍在核对，相关入口可能无法展示完整预设；发布前必须完成修复或明确豁免。

## 服务与数据说明
- 云存档、签到、新闻和股东名单依赖独立后端；若服务暂时不可用，本地客户端更新不会自动恢复这些服务。
- 不要为了更新而清除浏览器站点数据，以免影响本地设置或尚未同步的存档。

## 反馈
请通过游戏内“反馈问题”提交，并附上版本号、设备、操作步骤和截图。感谢你的反馈。

- [ ] 新内容、修复、平衡、已知问题分区齐全；空分区按规则处理。
- [ ] 数值、活动时间、奖励和赛季口径与策划/后端一致。
- [ ] 版本、上线时间、更新方式、反馈入口准确。
- [ ] 游戏内 news 与社区公告内容一致，发布时间经过审批。
