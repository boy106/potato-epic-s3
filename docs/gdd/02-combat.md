# 02 · 战斗、伤害与枪械（现状版 GDD）

> 出处：`mods/xzguns/bundle.js`（`XZ.R.guns/atts/ammo/bench`、弹道 trace、spreadNow）、`mods/index.json`、`index.html` boot TIP。数值全表见 `numbers.md` N-30~N-55。

## 1. 概述

10 把现代枪（+隐藏的 K 式步枪与榴弹发射器 = 代码里 11 个枪定义）、4 种子弹、9 种配件；子弹按方块硬度穿透；部位伤害（爆头 ×2、四肢 ×0.75）；移动/腾空散布惩罚；黑市平板商店用材料换枪。天梯统一装备，沙盒里自己造。

## 2. 玩家价值

- 每局固定枪的 Bo5 → 强迫玩家掌握全枪池，公平且有多样性。
- 硬度穿透 + 易碎玻璃 → 体素地图可被战斗实时改造（掩体消耗战）。
- 移动惩罚 + 急停辅助 → 走停节奏的射击手感，手机上也能打准。

## 3. 核心规则

### 3.1 部位伤害（N-40）

- 爆头：`×(枪.head || 2)`——默认 **×2**，左轮 **×3**（N-40/41）。
- 四肢：**×0.75**（腿部判定：命中点低于眼睛-0.3，且在腿部高度/半径盒内）。
- 躯干：×1。
- 「爆头击杀」判定（击杀图标/结算）：单发伤害 > 1.4 × 枪基础伤害（N-42）。

### 3.2 散布与移动惩罚（N-43~45）

```
基础散布 = 枪.spread[开镜?1:0]           // [腰射, 开镜]
握把:    ×0.75
激光:    腰射 ×0.6
移动因子 l = clamp((水平速度-0.05)/0.23, 0, 1)   // POTATO 版
有 move 属性的枪: 散布 += move × (开镜?0.5:1) × l
腾空:    散布 += move × (开镜?0.5:1) × (1-l)，且总散布 ×2
```
- boot TIP 印证设计意图：「移动中开枪会打飘，停稳再开」。
- 移动端瞄准吸附：按住开镜时辅助追踪（误差 <0.3rad 才保持吸附、移动/腾空时要求几乎停稳），吸附同时强制「急停」（halt 160~200ms 停走）。

### 3.3 穿透（N-46）

- 每把枪有 pen 值（穿透预算）。子弹穿过方块按硬度扣预算：
  - 易碎方块（玻璃/冰/灯/珊瑚扇/烛台等白名单）固定成本 0.1，且玻璃等一打就碎；
  - 木质（planks/log/门/栅栏等）：成本 = 0.5 × 硬度；
  - 其他：成本 = 硬度（下限 0.3）；
  - 不可破坏（硬度<0，如基岩）：成本 ∞。
- `mods/index.json` 明文：「子弹按方块硬度穿透，玻璃一打就碎」。

### 3.4 开火/操作（N-47）

- 左键开火（按住连发，全自动枪连发）；右键开镜（设置可选 混合/切换/按住，N-48）；R 换弹；F 检视（检视动画触发音效时间轴）。
- 换弹分「战术换弹」与「打空换弹」（reload_empty 时间轴更长，多拉栓/上膛动作）。
- 枪口制退器：后坐 ×0.75；消音器：枪声变小（静音枪声事件）；扩容弹匣：弹量 ×1.5；弹鼓：弹量 ×2.5、换弹 ×1.3 慢；瞄具：红点 zoom0.8 / 4 倍 zoom0.25 / 8 倍 zoom0.125。

### 3.5 黑市平板与商店（N-50~53）

- 进沙盒世界自动获得「黑市平板」：商店（材料换枪/子弹/配件）、改装（瞄具/枪口/握把/激光/弹匣 5 槽位）、设置（准星等）；创造模式免费。
- 商店价目见 N-51（10 枪 + 榴弹的材料单）与 N-52/53（子弹、配件材料单）。
- 平板「辅助」页提供作弊开关：无限弹药/无后坐力/秒杀/无散布（超管另有自动吸附/透视）；**对局（天梯/约战）不生效**（boot TIP 明文 + 进对局统一装备）。

## 5. 边界与异常

- 榴弹发射器 dmg=0 + grenade 标志，走爆炸伤害路径。
- 霰弹 8 弹丸独立判定，单弹丸伤害低于身体倍率基准（爆头判定 1.4×dmg 对弹丸同样生效）。
- 队友（2V2/乱斗重生的敌人标记）有 xzMate 免伤标记，弹道直接跳过队友实体。
- 击杀记录窗口：lastHit 5 秒内算击杀者。
- 靶场地图不可破坏、进出状态保持（xzrange mod，hidden，随枪械 mod 分发）。

## 6. 耦合

- 天梯：ROUNDS 枪池按枪名索引 guns 表；每局 UI 显示枪名与统一装备提示。
- 乱斗：重生按权重表随机发枪（N-61）。
- 经济（沙盒）：商店材料消耗 → 玩家挖矿动机。
- 皮肤系统：8 类枪有皮肤槽（GUN_CN），枪械本体与皮肤解耦。
