## 二、关键发现

1. **打包漏资源是系统性问题，不是孤立事件**：mod 内部打包链路 100% 完整（S-03：index.json 声明的 128 文件全在），但入口级静态资源连续漏了三类 —— `js/skins_data.js`（D-001）、整个 `potato/` 目录：logo.svg/bg.jpg/tiers/*.webp（D-005）、favicon（D-006）。推测打包脚本按「JS 引用扫描」收集资源，漏掉了动态拼接与 HTML 内联的引用。
2. **启动失败路径的用户体验差**：WebGL2 不可用时错误文案被 logo 遮挡（D-003）+ 加载条假死在 97%（D-004）。这条路径恰好覆盖低端机/未开硬件加速的玩家，是差评高发入口。
3. **正式包残留开发机地址** `127.0.0.1:8842`（D-008），对应功能在玩家环境 100% 失败；`NET_CONFIG.share` 为空串，疑似分享服务未配置。
4. **静默降级模式偏多**：skins_data（onerror→[]）、bg.jpg/tiers（canvas 兜底）都不提示。建议统一：资源缺失至少 console.warn 带资源名，玩家可感知的功能缺失给出 UI 提示。
