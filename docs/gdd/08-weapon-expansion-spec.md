# 08 · 枪械扩展规格（W11b / S3）

> 基线：`docs/gdd/02-combat.md`（现状版）与 `docs/gdd/numbers.md` N-30~N-61。数据出处：`mods/xzguns/bundle.js` guns/ammo/atts/bench 数据块（已逐字核对）、`js/sfe_mapdata.js` LOOT T0~T4 与 POI 配置、`js/sfe_poi.js` POI 管线。
> 本文档为纯规格，不含代码改动。工程侧落地方式见 §7.4。

## 1. 概述

现状 11 个枪定义（10 把在售 + 隐藏 K 式）、4 种子弹、9 种配件、改装 5 槽（optic/muzzle/under/side/mag，由每把枪的 `slots` 白名单控制可用配件）。本规格在其上扩展：

| 维度 | 现状 | 本规格后 |
|---|---|---|
| 口径/子弹 | 4 种 | **8 种**（4 现有重命名归位 + 4 新增） |
| 枪械 | 11 定义 | **+10 把新枪**（9 把正式 + 1 把彩蛋） |
| 配件 | 9 种 | **+5 种**（14 种，仍 5 槽） |
| 获取 | 黑市商店 | 黑市商店 + 搜打撤搜刮**双通道全覆盖** |

设计基调：**口径即身份**。每把枪先定口径，再由口径决定穿透基线与部位倍率默认值，枪本体在基线上做小幅个性偏移——避免凭空数值膨胀，也让"搜到什么弹"成为搜打撤的节奏驱动。

## 2. 玩家价值

- **搜打撤玩家**：口径稀缺性制造决策——捡到 7.62 但枪是 5.56，是换枪、回商店、还是留弹备用的取舍。
- **沙盒玩家**：新配件（两脚架/穿甲弹匣等）给老枪二生命，商店材料单延长挖矿动机。
- **天梯玩家**：不受影响（首版新枪不进 Bo5，见 §7.1），体验零回归风险。
- **收藏向**：每把新枪有明确"和谁抢、抢什么"，入手理由清晰，可配皮肤槽（§7.3）。

### 3.2 与 02-combat §3.1 部位倍率的联动规则

1. **优先级不变**：`枪.head 覆盖值 > 口径 head 默认 > 全局 ×2`。实现上口径默认直接写进枪定义 `head` 字段（现引擎即 `gun.head||2`），代码路径零改动；本表只约束数值来源，防止口径与枪配置互相覆盖时打架。
2. **四肢倍率全局锁定 ×0.75 不变**，口径不参与四肢修正——四肢特化留给配件与枪定位，避免规则面膨胀。
3. **爆头击杀判定 `u>1.4×dmg` 不变**。.45 口径 head ×2.5 天然满足；弹丸类（12ga）沿用现规则"单弹丸伤害对比弹丸 dmg"。
4. **pen 联动**：枪 `pen` = 口径基线 ± 微调；穿甲弹匣（§5）+1.5 后全场封顶 **7**（狙击基线 5.5+1.5=7），防止无限穿预算。pen 计费沿用 N-46 成本表（易碎 0.1 / 木质 0.5×硬度 / 其他 max(0.3,硬度)），口径不改成本公式，只改预算起点。
5. **迁移原则**：口径迁移只改枪的 `ammo` 指向，不动枪数值；受影响枪（左轮→.45、栓动/K式/轻机→7.62、狙击→.338）需同步改商店弹药价目与搜刮表口径（§6）。存量存档兼容：旧弹药 id 不删（`ammo_pistol/ammo_rifle/ammo_shell` 语义保留），不存在"旧档弹药失效"。

### 4.3 模型与音效策略说明

- **策略 A（变体复用）**：复制 bundle.js `g3:{...}` 内既有枪的元素集，改缩放/偏移/UV 指向（换色用 tiles.webp 既有 tile 条带重映射），改 `cn` 命名。**首版 ≥70% 新枪走此路线**（上表 1/2/3/4/6/7/8 共 7 把）。
- **策略 B（手写简化 bbmodel JSON）**：≤60 元素（DMR/土豆枪），UV 复用同口径枪的 tile 条带或图集空位。
- **策略 C（拼装）**：基础变体 + 既有配件/部件元素拼装（转膛榴弹复用 revolver 转轮 + launcher 弹体）。
- **音效**：全部复用 `sounds/` 现有 cues 时间轴（fire/reload/reload_empty 事件名不变），不新增音频文件；新枪 cues 直接引用旧音效键。
- **图集余量（工程风险）**：tiles.webp 为 1024 宽 VP8L，data.js tiles 注册 2072 个 tile、最大索引 3751（有稀疏空位）。新枪优先复用既有条带；确需新 tile 时走图集空位，落地前必须跑 UV 越界校验（§8 验收 8）。

### 5.2 槽位冲突矩阵（新 5 配件 × 现有 9 配件）

同一槽位内天然互斥（引擎一槽一件），下表只列**跨槽新增规则**：

| 规则 | 原因 |
|---|---|
| under 槽：两脚架 / 垂直握把 / 枪托稳定器 三选一 | 同槽互斥，且效果同源（稳定类）叠加会突破散布下限 |

| side 槽无新配件 | 激光独占维持现状 |
| muzzle 槽无新配件 | 消音/制退互斥维持现状 |
| 白名单制：新配件只在 §5.1 白名单枪的 `slots` 中注册，其余枪不可装 | 与现有 guns.slots 机制一致，零引擎改动 |

**禁止组合清单**（防数值叠加失控）：两脚架+枪托稳定器（同槽已防）；穿甲弹匣+两脚架同时作用于 DMR/远程狙击时需验收 DPS 上限（§8 验收 3 公式含配件）。

## 7. 模式准入与平衡护栏

### 7.1 天梯（Bo5）——首版不进

新枪首版**不进** Bo5 枪池（ROUNDS：手枪→左轮→冲锋枪→步枪→狙击枪）与淘汰赛 randGuns（8 枪等权）。理由：

1. **公平性契约**：Bo5 的核心是"固定枪池+统一装备"的公平承诺（02-combat §2）；新枪数值未经线上数据验证，进池即改变全体玩家的对局契约。
2. **学习成本**：Bo5 强迫玩家掌握全枪池，扩池=老玩家重学成本，且当前全服规模（排行榜 Top10 生态）撑不起分池匹配。
3. **迭代安全**：ROUNDS/ROUNDS_K 是哈希驱动的局序逻辑（N-55），改池牵连 match id 语义；首版绕开，二期稳定后再议。
4. **平衡观察期**：新枪先在乱斗/沙盒/搜打撤/自定义局收集 2~4 周强度数据，达标再评估进入**淘汰赛 randGuns**（低风险入口：每局随机、非排位计分），Bo5 扩池放最后。

### 7.3 皮肤

新枪 id 加入 skins_data.js 的 GUN_CN 8 类槽位体系时，沿用"枪械本体与皮肤解耦"原则；土豆枪**不开放**皮肤槽（彩蛋定位）。首版不给新枪配皮肤，仅预留槽位 key。

## 8. 总验收（13 条，均可测）

1. 口径表落地后，guns 表每把枪 `ammo` ∈ 8 种口径 id；黑市商店可购买全部 8 种弹药且数量区间与 §6.2 一致。
2. 新枪 ≥9 把（彩蛋枪可后置）每把三标注齐全：口径、差异化定位（对手枪 + 差异说明）、模型策略（A/B/C）。
3. **无纯数值膨胀**：每把新枪 DPS ≤ 其差异化对手枪 DPS ×1.1；带满配件（两脚架/穿甲弹匣等）后 DPS ≤ 对手满配 ×1.15。逐枪断言可脚本化。
4. 穿透封顶：任意 枪+配件 组合 pen ≤ 7；穿甲弹匣 dmg ×0.9 生效（单测比对伤害输出）。
5. 部位倍率优先级回归：`枪.head 覆盖 > 口径默认 > 全局×2`，用 .45 枪（head 2.5）与 5.56 枪（无 head 字段→×2）各打爆头比对伤害；四肢一律 ×0.75 不受口径影响。
6. 爆头击杀判定 `u>1.4×dmg` 在全部新枪上行为与现枪一致（含 12ga 弹丸判定）。
7. 槽位冲突矩阵（§5.2）全枚举：under 3 选 1、mag 4 选 1 在改装 UI 与数据层双重成立；非白名单枪装新配件被拒绝。
8. 模型落地：A 策略枪 ≥70%；B 策略枪元素数 ≤60 且 UV 全部落在 tiles.webp 既有条带或注册空位内（越界校验脚本 0 报错）；所有新枪无新增音频文件。
9. 新枪不进 Bo5 枪池与淘汰赛 randGuns（ROUNDS/ROUNDS_K/枪池数组 diff 为空）；乱斗权重表含新枪且每把权重 ≤ 1400×0.6=840（土豆枪 200）。
10. 搜打撤覆盖：§6.3 每类 POI 至少 1 种新口径产出；T4 深挖精英坑含 ≥2 种新枪；撤离点 0 物资不变；同 seed 掉落哈希一致性回归通过。
11. 存档兼容：口径迁移（左轮/栓动/K式/轻机/狙击换 ammo 指向）后，旧档持有的 `ammo_pistol/ammo_rifle/ammo_shell` 数量与可发射性不丢失；删除任何旧弹药 id 为验收不通过项。
12. 离线全流程：断网状态下，黑市材料单购买 + 搜打撤搜刮两条路径均可获得至少一把新枪、一种新弹药、一种新配件。
13. 回归无损：不装备任何新配件时，现有 10+1 枪的散布/后坐/穿透/部位伤害输出与 02-combat.md §4 数值表逐字段一致（自动 diff 0 差异）。

## 9. 开放问题

1. **口径迁移深度**：左轮→.45、栓动/K式/轻机→7.62、狙击→.338 是一次性硬迁移（弹药体系更清晰）还是并存过渡（旧弹保留可买，双价目）？并存会加长价目表与搜刮表，硬迁移需公告老玩家。倾向：硬迁移 + 商店旧弹一次性折算。
2. **左轮爆头文案统一**：.45 引入 head ×2.5 后，OQ-7（左轮 ×3 与全局 ×2 文案冲突）必须同步定稿——建议对外文案统一为"部分大口径枪爆头倍率更高，见枪械详情"，避免逐枪报倍率。
3. **转膛榴弹与土豆枪的取舍**：转膛榴弹（6 连发爆炸）是本规格唯一可能动摇爆炸平衡与帧预算的枪；土豆枪"命中掉土豆"需要弹道命中回调，工程成本高于普通枪。两者是否首版同上，还是先上转膛、土豆枪 P2？倾向：土豆枪 P2。
