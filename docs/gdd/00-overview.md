## 1. 游戏一句话

浏览器端（B站 Toy 平台独占）体素 FPS：以自制「小哲的现代枪械」模组为战斗核心，套 Elo 天梯排位（1V1 / 2V2 / 8 人淘汰赛）、人机练习、好友约战、靶场训练，外挂土豆币经济 + 皮肤/装饰收集 + B站生态解锁（关注/三连/股东）。

## 2. 现状版设计支柱（从现有玩法反推，非官方宣言）

| 支柱 | 证据（现状里反复出现的取舍） |
|---|---|
| **P1 碎片时间·轻竞技** | Bo5 强制打满五局（每局 ≤90s，N-56）；人机随时开打不排队；匹配「平均 1 分钟内」文案；对局时长上限 12 分钟计币（N-63）；手机端触控 + 瞄准吸附 + 急停辅助 |
| **P2 公平竞技、读装备取胜** | 天梯统一装备、每局固定/随机枪（不能带自己的枪，N-54/N-58）；「每局随机抽一把枪」淘汰赛；同段位优先匹配；Elo 双表（赢分递减、输分递增） |
| **P3 B站生态绑定** | 排位资格门=关注 UP 主；薯核 CORE 枪皮+刀=关注+三连；股东名单=关注后加入送动态披风；登录/账号、邀请码社交全围绕 B站身份 |
| **P4 收集与表达** | 皮肤 4 级成长（击杀反馈→检视动作→终结特效）、涂装、名牌框、披风、装饰；涂装/升级全用免费获得的土豆币 |

> 红线检查：未发现主导策略（皮肤纯表达、无数值属性加成——皮肤只改特效，不改伤害）；经济无硬门槛（钱只能靠玩+签到）；B站门是唯一「非玩解锁」，见 open-questions OQ-2。

## 3. MDA 反推

- **机制（M）**：体素射击（部位伤害/穿透/散布/移动惩罚）+ Elo 天梯 + 局内固定枪池 Bo5 + 土豆币（时长/首胜/签到）+ 解锁门（段位/关注/三连/活动）+ 装饰收集。
- **动态（D）**：玩家在 800 分以下可用人机稳定刷分（胜场×难度系数）→ 低段位爬升快；800 分后必须打真人 → 社交/匹配压力转移；连签 7 天后 1000/天 → 每日打开动机；淘汰赛「同轮出局按伤害排名」给输家二次目标；击杀反馈/终结特效给枪皮升级即时回报。
- **美学（A）**：挑战（爬梯/段位）、竞技公平感、表达（外观）、放松消遣（乱斗明写「图个痛快」不加分）、社群归属（股东名单/伙伴 AI）。

## 4. 核心循环（现状）

```
登录（B站） → 大厅
  ├─ 天梯排位（关注门）→ Bo5 → Elo 结算 + 土豆币(15/min + 首胜)
  ├─ 人机对战（随时）→ 胜场 ×10/25/50% 天梯分（<800 分）+ 币
  ├─ 好友约战（邀请码/房间码）→ 自定义规则 → 币(9/min + 击杀补时)
  ├─ 靶场训练 → 教学/练枪 → 币(3/min)
  └─ 衣柜/枪皮：土豆币 → 升级特效(100/250/500)、买涂装(300)
每日：连续签到 300→1000 · 活动签到（装扮） · 赛季段位解锁 AR 皮肤
```

## 6. 一局（回合）时间参数

- 准备阶段 3s → 战斗 90s → 结算 3.5s（N-56）。

- FFA 死亡重生 3s。
