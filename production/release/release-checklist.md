# POTATO EPIC 上线清单（G2）

- 适用：B站 Toy 纯静态客户端 + 独立后端 rooms/pm
- 使用：复制为每次发布记录，逐项填写证据链接、执行人、时间和结果。
- 门控：**所有 P0 必须通过；P1 未完成需用户书面豁免；任何 Blocker 未清均为 NO-GO。**
- 结构：A–F 为常规 44 项；G 为陀螺仪新功能专项（功能随版发布时启用）。
- 当前包审计只证明静态结构，不等价于浏览器、后端或 Toy 容器验收通过。

## A. 候选范围与审批（6 条）

- [ ] **A01 / P0**：冻结唯一候选目录，记录 `BUILD`、赛季、上一稳定版、发布类型和完整包 SHA-256。
- [ ] **A02 / P0**：代码与内容冻结；冻结后任何字节变化都重新分配版本并重跑相关检查。
- [ ] **A03 / P0**：QA 报告无未豁免 Blocker；崩溃、无法进入、存档损坏、付费/奖励错误均不得带险上线。
- [ ] **A04 / P0**：代码、内容、QA、发布负责人完成 go/no-go 签字，明确最终审批人。
- [ ] **A05 / P0**：记录客户端与 rooms/pm、存档结构、live/news 配置的兼容范围，不以后端“应该兼容”代替验证。
- [ ] **A06 / P1**：商店文案、法务/隐私口径、社区公告和客服已知问题口径已核对。

## B. 静态资源完整性与 mods（10 条）

- [ ] **B01 / P0**：在干净目录解压上传包，无绝对路径、临时文件、旧版混入或解压错误；记录文件数与总字节数。
- [ ] **B02 / P0**：生成逐文件发布清单（相对路径、字节数、完整 SHA-256），后续用于差异审计和回滚校验。
- [ ] **B03 / P0**：`index.html` 的 script/preload 引用全部返回 200，MIME 正确，路径大小写与线上一致。
- [ ] **B04 / P0**：扫描动态脚本引用；`js/skins_data.js` 必须随包且能产生 `SKIN_PRESETS`，或由代码负责人移除依赖并验证入口，禁止静默 404。
- [ ] **B05 / P0**：`chunk_worker.js`、`gen_worker.js`、`worldgen_data.js`、`blockdata.js`、`modapi.js` 等独立资源按真实运行路径验证，不能只查四个 pack。
- [ ] **B06 / P0**：`mods/index.json` 可解析，mod ID 唯一；代码侧 `MODS_ALWAYS` 常量（包内仅见读取 `MODS_ALWAYS||[]`，未找到赋值，需代码负责人确认来源）所指的内置 mod 均可加载，父子/靶场引用有效。
- [ ] **B07 / P0**：逐个核对 mod `files`：无缺失、无未登记运行资源；当前基线为 116 个登记文件，而非永久固定数量。
- [ ] **B08 / P0**：mod 内容变化时版本已递增；`size` 与实际下载字节口径一致，断点续传/进度显示经过验证。
- [ ] **B09 / P0**：贴图与双格式音频齐全；当前基线 55 个 OGG + 55 个 M4A，逐一检查解码、大小写和路径。
- [ ] **B10 / P0**：通过全新浏览器配置在静态服务器实测，网络面板无意外 404/403、CSP/CORS 错误或 JavaScript 异常。

## G. 新功能发布检查项（陀螺仪 · 移动端体感瞄准）

- 适用：三档开关 + 双灵敏度滑条的陀螺仪瞄准功能进入实现后启用本节；正式随版发布时并入该版 checklist 一次性勾选。
- 代码实证：`pack4.js` 已引用 `DeviceOrientationEvent` / `DeviceMotionEvent`，属移动端专属能力，验证必须以真机为准。

- [ ] **G01 / P0**：新增资源打包完整性：陀螺仪相关新增 JS/数据/文案（若挂载于 mod 则同步 `mods/index.json` 的 `files`/`size`）逐文件登记并核对 SHA-256；动态请求的文件必须随包存在，参照 `skins_data.js` 漏打包教训，禁止静默 404。
- [ ] **G02 / P0**：移动端真机权限流验证：iOS/Toy WebView 容器下 `DeviceOrientationEvent.requestPermission` 必须在用户手势回调内调用；验证首次授权、拒绝授权两条路径，拒绝后回退触屏瞄准，不白屏、不卡死。
- [ ] **G03 / P0**：三档开关逐档真机生效且设置持久化（重进游戏保留）；双灵敏度滑条（视角/瞄准）独立调参互不干扰。
- [ ] **G04 / P0**：前后台切换、锁屏/解锁、旋转屏幕后体感事件自动恢复，无需重新授权或重启。
- [ ] **G05 / P1**：无陀螺仪传感器或系统不支持时的降级：开关隐藏或置灰并给出说明，不影响触屏玩家。
- [ ] **G06 / P1**：telemetry 增加开关档位与使用状态打点，上线后可观测真实使用率与异常率。
- [ ] **G07 / P1**：设置持久化不改变云存档/本地存档结构兼容范围；若涉及存档结构变化，按 versioning.md 记录 `save_revision`。
