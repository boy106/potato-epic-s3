# 04 · 元系统与留存（现状版 GDD）

> 出处：`js/pack4.js` 解包模块（checkin.js / shareholders.js / companion.js / cosmetics.js / onboard.js / social.js / p2p.js / net.js / account.js / news.js / toy.js）、`mods/xzguns/bundle.js`（每日连续签到、活动事件定义）、`index.html` boot TIP。

## 1. 概述

留存侧有四层：每日打卡（连续签到 + 活动签到）、赛季（段位皮肤 + 榜单）、B站生态社交（关注/三连/股东/约战）、陪伴系统（AI 伙伴）。全部免费，无推送痕迹（Toy 平台宿主）。

## 2. 玩家价值

- 每天两签（连续签到 1000/天 + 活动装扮），登录理由密度高。
- 股东名单/伙伴 AI 制造「在游戏里有我的位置」的归属感。
- 好友约战用邀请码，把社交拉新放进游戏内。

## 3. 核心规则

### 3.1 每日连续签到（N-66）

- 连续第 1~7 天：300/400/500/600/700/800 币，**第 7 天起每天 1000**。
- 断签：连签归 1 重来；累计签到天数另计展示。
- UI：「土豆币靠签到和游玩获得…用来升级枪皮」。

### 3.2 活动签到（两个并行事件系统，N-80~84）

| 事件 | 窗口 | 奖励 | 规则 |
|---|---|---|---|
| 薯光丰收节 harvest2026 | 2026-11-18 ~ 2027-01-01 | 第 1~8 天：8 把丰收节枪皮；第 9 天：「丰收」名牌框；每天另 +30 币 | 按活动日历逐日领（代码 days:9） |
| 开服签到 · 冬日足迹 | 开服期 | 10 件装饰（草帽/礼帽/皇冠/小雪人/土豆前缀/企鹅披风(动态)/金苹果披风/灯笼小精灵/厨师帽/冶炼炉披风） | **累计满 N 天即可，不要求连续**；结束后装扮永久保留 |

### 3.3 赛季（N-85）

- 客户端仅展示「第一赛季 · 五局三胜 · 打满五局」；赛季身份、榜单、晋升皮肤门槛由服务端（/api/ladder/* + gate）承载。
- 重置/软重置规则客户端零证据 → OQ-5。

### 3.4 股东名单（N-86）

- 前提：关注 UP 主 → 用 B站昵称加入名单（虚位以待/实时列表/烟花特效欢迎页）。
- 加入即送动态披风「烟花夜空」，退出名单披风保留；可重复加入。
- 名单支持「找到我」定位、名次显示。

### 3.5 AI 伙伴（N-87）

- 主菜单/游戏内陪伴：场景感知（维度/坐标/天气/背包）、主动说话（进度/死亡/进新维度触发，2 分钟限频）、V 键/聊天唤起对话、记忆系统（可清空）、快捷帮改设置、帮填反馈。
- 说话内容与设备支持检查（不支持光影会说明）。

### 3.6 好友约战与社交（N-88）

- 大厅「好友约战 · 自定义房间 · 房间码」：房主建房生成邀请码，复制发给朋友；P2P/服务器双通道（net.js + p2p.js + social.js）。
- 房主配置：局数 3/5/7、枪规则（固定/每局随机/预设池）、天空、规则开关；房主权威结算。
- 2V2 可好友组队（party 系统，房间成员列表/邀请）。

### 3.7 引导（N-89）

- 首启流程：用户协议+隐私 → 设备选择（手机/平板/电脑，其中一档标「推荐新手」）→ 操作教学选择：「新手训练（约 2 分钟，枪直接发到手上）」步骤=移动/跳跃下蹲/滑铲/开火/开镜/换弹/爆头/急停/连杀，或「直接进大厅」。
- 靶场训练控制台随时可重开「教学」；靶场卡片在模组界面。
- boot TIP 轮播（加载页）：R 换弹 · F 检视 · 右键开镜／天梯五局三胜，五局都要打完／好友约战：把邀请码发给朋友／平板「辅助」页能开无限弹药（对局里不生效）／移动中开枪会打飘，停稳再开（N-90）。

### 3.8 Live Ops 基础设施

- news.js：更新公告 + 公告礼物领取。
- telemetry/anticheat：行为上报 + 分数异常封禁（1h）。
- cloudsave：账号云存档（币/皮肤/签到状态跨设备）。
- share：大厅分享/邀请传播。

## 5. 边界与异常

- 签到重复点击：抛「今天已经签到过了，明天再来」。
- 活动未开始/已结束：明确文案 + 结束后显示「你领到了 N 件装饰，永久保留」。
- 服务器未配置：签到/天梯入口给「还没有配置游戏服务器地址」「游戏正在更新中…请稍后」。
- 断签重置只影响连签奖励档，不影响累计天数与活动签到。
- 股东退出再加入披风不重复回收。

## 6. 耦合

- 03 经济：签到是土豆币最大稳定来源（7 天起 1000/天 vs 游玩 15/min → 签到 1 天 ≈ 66 分钟排位时长）。
- 01 排位：关注门/赛季段位展示/榜单。
- 02 战斗：新手训练步骤与枪械机制一一对应（急停=移动惩罚反技能）。
