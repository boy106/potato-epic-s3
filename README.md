# 土豆史诗 · S3 玩法扩展（离线版）

B 站 Toy 平台浏览器游戏《土豆史诗》的完整项目归档：从发布包逆向还原的源码、设计/架构文档、构建工具与 S3 轮构建产物。

## 目录

| 目录 | 内容 |
|---|---|
| `src/` | 还原后的源码树（104+ 模块）+ mods（小哲的现代枪械、靶场） |
| `docs/gdd/` | 游戏设计文档（战斗、天梯、经济、陀螺仪、搜打撤、S3 玩法扩展规格） |
| `docs/architecture/` | 架构基线、ADR、模块地图、搜打撤大地图方案、实现/诊断报告 |
| `tools/` | 构建脚本（`build.mjs`，版本单源 + 完整性自检门）、验证脚本、打包顺序 |
| `dist/` | **可直接部署的构建产物**（111 模块，BUILD 2026.11.14a） |
| `production/qa/` | 缺陷台账、冒烟测试、验收证据 |

## 快速开始

`dist/` 是完整可玩的离线包：把该目录放到任意静态服务器（如 `cd dist && python3 -m http.server 8080`），浏览器打开 `index.html` 即可。

从源码重新构建：

```bash
node tools/build.mjs      # 输出 dist/
```
